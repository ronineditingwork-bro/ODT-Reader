# ODT Reader

Простое Android-приложение для локального чтения файлов **.odt**.

## Возможности
- выбор ODT через системный проводник Android;
- открытие через системное меню «Открыть с помощью»;
- чтение текста без отправки документа в интернет;
- сохранение абзацев, заголовков, табуляции и переносов строк;
- изменение размера текста;
- светлая и тёмная тема;
- автоматическая сборка debug APK через GitHub Actions.

## Сборка APK
Откройте вкладку **Actions** → **Build Android APK**. После успешной сборки APK находится в артефакте **ODT-Reader-debug-apk**.
